# Pokémon TCG 1996-1997 舊裏卡收藏清單

單一檔案的網頁 App（只有 `index.html`），用瀏覽器就能開，記錄 1996-1997 年日文舊裏卡（第1弾・ジャングル・化石の秘密・ロケット団，共 263 張）的**持有數量、市價、成本與備註**。

線上版：https://kwanabc.github.io/96-97-card-list/

## 資料存在哪裏

| 位置 | 內容 |
|---|---|
| 瀏覽器 localStorage | `tcg96_inv_v1`（收藏紀錄）、`tcg96_ui_v1`（篩選條件）、`tcg96_backup_v1`（本機自動備份，保留最近 8 份） |
| **GitHub 私人資料庫** | `kwanabc/finance-vault` 的 `96-97-card-list.json`（跨裝置共用，只有本人登入 GitHub 才看得到） |
| 下載的備份檔 | 用「下載備份」匯出的 JSON，手動救命用 |

## 跨裝置使用（手機／其他電腦）

1. 打開網址 → 右上角 **「雲端同步設定」**
2. 貼上 GitHub 授權碼（token）→ 按「**儲存並同步**」
3. 狀態顯示 **🟢 已同步（GitHub）** 就成功

授權碼**三個網站共用同一組**（貸款追蹤、PokéVault Pro、本頁），所以在任一個網站設定過，其他兩個會自動帶入。授權碼只存在該台裝置的瀏覽器裡，**不會**寫進這個公開的網頁檔案。

## 同步機制（為什麼不會互相蓋掉）

- 每張卡的紀錄帶一個 `u` 時間戳，每次編輯就更新。
- 合併時**逐張比對**：`u` 比較新的那一邊勝出，所以兩台電腦改不同卡片不會互相覆蓋。
- 上傳前會先讀雲端並合併一次，再寫回；版本衝突會自動重讀重試一次。
- 本機永遠優先可讀：沒網路時照樣能輸入，恢復後自動補送（改動後 1.2 秒去抖動上傳、每 30 秒補送一次）。
- 新電腦第一次打開：雲端檔案不存在且本機已有資料 → 自動上傳一次。
- 雲端資料格式會驗證，格式不對的紀錄一律跳過，不會寫進收藏。

## 其他功能

篩選（系列／關鍵字／屬性／稀有度／是否擁有）、排序（編號／PSA 10 存量／持有數量／價錢／名稱）、HKD ⇄ USD 切換、PSA 10 存量數字與 PSA 官方報告連結、匯出 CSV、下載／還原備份、↶ 撤銷（Ctrl+Z）、`/` 快速搜尋、`Esc` 關閉視窗。

## 卡圖來源

目前 `CONFIG.imgMode = 'cdn'`：日文卡面取自外部空間（`aplnyshrkrgbselitojs.supabase.co`），載入失敗時自動退回英文大圖（`images.pokemontcg.io`），並已加 `no-referrer`。
若外部空間哪天關掉，可改成 `'local'` 使用自己放在 repo `images/` 資料夾的圖（需先上傳圖片）。
